## 实现边界与集成复核

工具准备、主体进入、放弃和最终结算使用单次状态转换。必需的持久审计失败阻止发送或重试；已有执行失败作为首因保留，清理与观察失败附加。已知执行前拒绝明确标记未产生副作用；主体进入后无法确定的结果保持 UNKNOWN，不从错误码白名单推断安全。取消与超时可保留原始原因，同时以 sideEffectUncertain 阻止续跑。子任务只交付完成消息，由父线程写持久事实；文件通道的物理结算围绕中断标志清除/恢复，晚到子任务不得再次写父日志。

环境关闭撤销已借出的文件和注册能力，随后尝试全部清理；队列、监听器、插件回滚、进程采样及终端停止都有资源边界。进程树采样不能证明任意敌对进程的 OS 隔离，采样溢出与未确认清理保持未知；Docker 使用固定缓存镜像和既有隔离策略。Web 慢请求体与磁盘目录读取移出全局监视器，在受理时重查状态；不合作的旧 worker 退出前保留写锁。展示读取或队列暂停落盘失败均不能跳过 SDK 关闭及等待者通知。

秘密按标准化敏感字段名、已知值和流式前缀处理，先脱敏再截断；歧义 key 碰撞拒绝，敏感关联 ID 在执行前拒绝。原生 worker 以 UTF-8 字节限额校验完整批次，输入缓冲在退出时清零；父进程的 stdin/响应交换纳入有界等待，写入或删除开始后的通信失败保守分类为 CREDENTIAL_UPDATE_UNKNOWN。配置持久化和凭据更新失败保留补偿/待清理信息，不将不确定更新当成功。可信 Java 插件、JVM String 的不可擦除副本和未运行的原生 POSIX 平台不在本机回归的隔离或内存清零保证内。

费用检查基于最终 prepared 请求的消息、工具 schema 和参数执行，发送前验证保守上界；不承诺任意供应商隐藏提示或分词器的精确计费。完成证据检查最新实际执行的验证命令、写入后的时序和真实文件版本，拒绝模型文字、缺失/非整型退出码与未知写入冒充完成。问题回答 v2 不存原始秘密文本哈希，重启后比较同一脱敏策略下的文字；脱敏等价回答不承诺原文相等，详见 M10.5.5 契约补充。

集成过程中发现并保留过失败记录：非 Git 工作区的长诊断不应掩盖 GIT_DIFF_UNAVAILABLE；MCP 回滚故障必须注入实际 MCP 注册位置；已拒绝执行的版本/配额检查不应被一律升级为 UNKNOWN；真实超时保留 TIMEOUT，但仍阻断未决副作用的续跑。流式截断标记必须跨装饰器传递，不能因中间安全截断而误报完整。最终证据以本阶段新回执为准，不能复用原 410 项历史通过数。
