# M10.5.5 主动提问契约

2026-10-18 已完成本地验收。SDK默认提供作用域内UserQuestionService与ask_user工具，每次一个single/multiple/text问题；选项2～8个，text无选项，问题2048/回答4096字符，等待1～300秒，同会话最多64题。推荐只做预选，必须明确提交，skip/timeout/cancel独立状态且不伪造答案、不授权工具或计划。

执行工具的单写者落盘question.requested/resolved并flush，关联session/turn/step/call及宿主生成questionId；HTTP线程只交付答案，不并发写JSONL。回答使用独立requestId+内容哈希；相同回答幂等，不同回答/关联/迟到或跨会话拒绝。SUBMITTED是尚未确认持久的临时状态，客户端必须GET核对后才算回答完成；丢响应不自动POST重放。

取消/总预算终止等待并持久记录，工具取消不变成成功。超时/跳过作为明确无答案结果返回模型。宿主退出后未完成问题显示INTERRUPTED并拒绝迟到回答，不自动恢复等待或重放。UI草稿经鉴权draft接口保存到宿主当前问题的脱敏内存，刷新从GET恢复；不写浏览器存储、JSONL或配置，宿主重启/过期后丢弃。浏览器仅存待核对requestId，未收到草稿保存确认前不承诺恢复；持久答案经原脱敏器进入工具结果与下一prepared请求。

API/SDK1.11，事件格式1和Web目录4保持。UI沿用既有DeepSeek视觉/组件，问题与工具审批分区，回答不改变原模型/预算/权限。验收需真实SDK工具→Chrome→下一模型请求，以及重复/迟到/跨会话/断线刷新/超时取消/脱敏与审批边界。无付费请求、参考目录修改或远端推送。


实现补充：ask_user声明requiresSerialExecution，即使列入只读并行白名单也先完成屏障、在owner线程执行，HTTP不写事实。截止前受理的答案在等待线程延迟恢复后仍结算，不被后观察的超时丢弃。宿主草稿有revision，旧版本拒绝DRAFT_CONFLICT；单卡只发送一个在途保存，完成后才保存最新编辑。问题待答时隐藏但不卸载续聊区，保留已有未发送草稿。问题列表按每页8条、会话最多64条有界读取，旧页不隐藏全局待答事实；中断后只显示INTERRUPTED不自动续问。

## 公共入口

- SDK：HarnessSdk.questions() 返回会话作用域 UserQuestionService；ask 由真实工具管线调用，list 查询事实，draft 保存脱敏内存草稿，respond 接收回答。普通调用者不能伪造已经执行的工具关联。
- GET /v1/tasks/{id}/questions?offset=0：最新8条，offset从最新端计数，返回questions、total、offset、hasWaiting；offset超范围拒绝。hasWaiting覆盖全部问题，不因查看旧页而消失。
- POST /v1/tasks/{id}/questions/{questionId}/answer：questionId、sessionId、turnId、callId、requestId、selected、text、skip。受理202 SUBMITTED；相同持久回答200；关联/冲突/关闭409，格式400。只有服务端持久结算为ANSWERED后才算回答完成。
- POST /v1/tasks/{id}/questions/{questionId}/draft：同一关联加selected、text、revision，成功返回脱敏selected/text与递增revision；旧revision拒绝DRAFT_CONFLICT。推荐不因保存草稿而提交。
- 全部HTTP入口沿用同源会话、loopback、Host/Origin校验。普通CLI未直接装配SDK的入口不增加交互提问提示；SDK、生态CLI及Web serve使用公共默认插件。JSONL新增question.requested/resolved事件，不修改旧事件格式，不迁移目录。

验收和命令见[M10.5.5记录](../testing/M10.5.5-validation.md)，用户操作见[提问说明](../examples/m1055-questions.md)。

## 2026-10-21 R1 安全与关闭补充

新回答写入`answerFingerprintVersion=2`：摘要只包含非文字关联字段、选项、skip与requestId，不对原始text留下可离线猜测的摘要。重启核对必须使用同一脱敏策略，对脱敏后的text另作相等比较；公开文字冲突仍拒绝，但脱敏结果相同的不同原文无法区分。这是脱敏等价回答的幂等核对，不承诺原始秘密文本的精确相等。旧事件保持原字节，只有旧版记录按原摘要算法读取，不补写或迁移历史秘密摘要。

stop先撤销受理，再最多等待两秒，由原工具线程完成唯一一次question.resolved与检查点；已在截止前受理的答案优先结算。未观察到owner退出时报QUESTION_SETTLEMENT_PENDING，不清空pending或伪造已持久化，不允许停止后的HTTP新增回答。
