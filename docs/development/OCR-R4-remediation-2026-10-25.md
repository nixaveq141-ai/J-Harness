## 本轮改动

- 扩展配置按 MCP/技能根16字符、技能24字符、角色32字符分别提示 ID 边界。添加条目检查碰撞；脚本超时空值保留字符串草稿，禁止变成0/null；保存前核对数值、类型、重复 ID、传输、URL、环境变量、资源/脚本与角色必读项。表单保留原始 argv 空格及非法高级 JSON 数据，不以修改其他字段覆盖它们。文件系统和权限判断仍由宿主负责。
- 会话元数据/导出、问题草稿与核对、详情查询在连接替换或卸载后不再写回旧响应。内容读取身份变化会先重新挂载内部读取器，重置 offset、版本、下载占用和旧提示。工作区达到16个时禁用注册；技能正文展开时才创建 DOM。
- 事件/查询页拒绝重复 ID、空续页和不前进的游标；内容检索核对累计总数和最后一页完整性。受控事件 ID 与分叉输入统一128字符。内容检索打开来源沿用导航守卫和连接身份检查。
- `RoutedLlmClient` 转发两类展示订阅，也保留未来路由的装饰。多个展示观察者逐个隔离，早先观察者抛错不阻止后续观察者或改变模型完成结果。临时显示不可用时保留可见诊断，事实读取结算失败仍传播并保留 UNKNOWN。
- CLI 报告使用独立的字符、节点、深度和每节条数预算。先完整脱敏，再截断目标、状态说明和事实正文；保留来源 eventId/callId/turnId/timestamp、截断标记、每节观察/保留/省略计数及原日志回读说明。报告不是完整日志副本；截断不改变任务成功、失败或未知状态。预览也有独立预算，`executed=false` 不变。
- 诊断保留未结算调用的确切声明事件、轮次和步骤；取消竞争测试包含真实 `turn.ended/CANCELLED` 事件。CLI 生态测试读取实际报告，核对交付哈希、成功读取和模型叙述分区，不再只数文件。
- 静态 Pill 使用 span 属性类型并透传语义属性，交互 Pill 保留显式 submit 能力和安全默认 type。hover 反馈限定有悬停能力的指针；viewport 滚动条有原主题兜底，圆点/圆按钮明确使用 round。移植文件摘要和修改说明同步更新。历史页键盘用例改为真实 Tab 进出与 `document.activeElement` 核对。
