# M10.5.6 对话、流式、文件与交付展示契约

2026-10-18，已完成本地验收。继承现有DeepSeek视觉与控件，以用户/助手对话和工具结果为主线，原始事件仍可检查。Markdown只支持安全的标题/段落/引用/列表/链接/代码等文本子集，HTML和危险URL不执行，图片不自动请求。文件引用仅在用户明确点击后按当前会话工作区鉴权读取。

新增公共ContentInspection和ModelDisplay服务，API/SDK1.12；JSONL格式1、Web目录4不变。ContentInspection只读，注册根、原路径保护/策略、文本和版本界限保持；独立观察视图不为模型写入建立版本依据。文件最多1MiB，目录单层最多200项；文本页最多16384字符，版本变化明确冲突。目录遵守既有过滤，不提供越界根、元数据、链接或二进制回退。

产物必须由本会话事件明确引用，ArtifactStore按作用域验证原ID/SHA；先完整脱敏再分页，受控下载验证脱敏后内容SHA，原始产物SHA独立显示。大事件正文同样按明确eventId鉴权、有界分页回读，读取不写事实。缺失/过期/损坏明确拒绝，不跨会话回退。

实时输出仅来自原StreamingLlmClient的跨块秘密保留窗口；新增只读ModelDisplay快照含会话/轮次/步骤/sourceEvent，最长65536字符，宿主内存暂存、不写JSONL。只有完整且已持久的模型事实算正式答案；断流/取消/刷新不重发请求、不伪造已丢字节。用户可停止本页显示或沿原取消入口取消任务；页面切换中止读取。

用量来自model.observed/提供方usage与实际记录的耗时。未提供token/费用显示未知；费用上界明确非实际账单。当前文件内容与当时记录Diff分别标记，不自动执行Git。测试覆盖真实SDK/HTTP/Chrome、安全Markdown、长输出/跨块脱敏/断流、目录边界/版本冲突、产物哈希/分页和移动/键盘。

过程记录（历史状态）：后端与首版TS/Vite已编译；文件/产物8项专项通过，流式专项发现状态错误使用不存在的model.responded类型，已改为实际assistant.message事实，复验中。SDK已接入model.observed元数据；文件翻页校验原文件版本，下载另核对完整脱敏内容摘要。最终全量/Chrome尚未完成。

API补充：LlmClient.withDisplay为可选累积观察接口；DataSanitizer.streamingText默认不展示临时字节，SecretRedactor与WorkbenchSettings实现所有已知秘密的尾窗，chain合并环境与系统凭据秘密。SDK独立观察流已通过组合脱敏专项；文件服务SDK注册绑定sessionId并经策略扩展点，不允许借公共查看服务读取其他会话产物。CLI的非local环境明确INSPECTION_UNAVAILABLE，不回退宿主；该只读文件入口目前支持本机注册根。

HTTP均为既有鉴权下GET：任务下files（单层树）、file（当前文件）、artifacts及artifacts/{id}（持久引用）、content/{eventId}（完整事件正文）、display（临时快照）。path使用UTF-8的base64url无填充编码；分页offset/line/version明确受控。file.version是原文件SHA，其他version是完整脱敏内容SHA；下载再校验contentSha256，文件版本与脱敏摘要不混用。每页16384字符，Unicode代理对不拆分。下载仅text/plain的.txt，不执行HTML/脚本。

过程记录（历史状态）：新增文件/流式/HTTP及组合脱敏专项通过，原13问答和23只读子任务回归通过；首版Chrome完整链路通过。独立UI审查指出产物ID挤压复制按钮，已改固定语言标签与禁止按钮收缩；增加保留挂载的移动输入折叠、结束摘要和记录Diff显式当前路径。更新后的最终Chrome及全量仍待完成。

ArtifactStore新增有界readText；LocalArtifactStore单次完整读取仍验证作用域、链接、4MiB和原SHA，再交完整脱敏/分页。避免每个16Ki字符显示页在存储层重复循环十余次完整读。临时显示按50ms或16Ki字符增长更新；即使秘密尾窗暂未释放可显示文本，也明确显示生成/中断状态。
