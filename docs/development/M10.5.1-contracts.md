# M10.5.1 契约：事实诊断与离线交接

2026-10-17，已完成本地验收；验收见 `docs/testing/M10.5.1-validation.md`。本片不实现多轮、工作区切换、历史扩容或模型协议适配。

## 身份与兼容

Workspace 是宿主验证的真实根路径及绑定，不是浏览器提供的任意路径。Profile 是可信装配选择。当前 Task 是一次持久受理的 Web 提交，taskId 同时是其 SDK sessionId；Session 是追加事件日志，Turn 是其中一次 Loop 输入，Step/Call 是轮次内请求及工具关联。requestId 只用于提交幂等，catalog 存其 SHA256（requestHash），不把 hash 冒充原 ID。配置由 config.selected 的 selection/resolved 捕获；settingsRevision 是所用设置修订，修改设置不会改写旧快照。

诊断为新增、只读、同源鉴权 GET `/v1/tasks/{id}/diagnosis`，schemaVersion=1，与 SDK 协议1.9和事件格式1独立；旧接口/事件不变。返回有限问题、关联、SessionRecovery 未决集合及离线步骤，不接受在线核实写入。老记录缺字段显示未知，不推断为否；无需重写 catalog/JSONL。旧设置无 policy 时继承启动配置（默认 default）；新字段可选，旧客户端保存时保留当前值。后续改变身份/格式需独立版本协商、备份与迁移契约，不在本片虚构尚不存在的 Workspace/Turn 写接口。

## 诊断依据与服务边界

诊断服务位于 harness-web，读取公共 SessionEvent 和 harness-session 的 SessionRecovery；CLI 设置组合位于 harness-cli。Loop 无新依赖。问题只摘取实际结果/结束事件，保留 eventId/turnId/stepId/callId；有界显示最近结果，完整日志仍走分页/搜索。参数/错误码、拒绝、取消、超时、模型/网络、未确定结果分别展示。工具管线 bodyEntered 与命令进程是否启动是不同层：SHELL_REQUIRED + cleanupStatus=not_started 证明命令主体未启动，即使管线进入工具包装器。observedClean/空 residualPids 或 environment.closed=SUCCESS 不能证明任务成功/所有资源无残留。

Web诊断对摘取字段先脱敏再截断，并在HTTP响应边界再次脱敏。旧的“Approval expired or cancelled”仅展示为无法区分，不能擅自解释成明确过期；新增记录分别保留实际过期/取消事实。

没有事实时不填0、不伪造期限/成功。诊断不执行命令、不调用模型、不换模式/放宽审批、不追加核实、不按历史PID终止进程。命令模式错误仅解释 ARGV 与显式 Shell 模式及重新审批要求。在线读取的 pending 集合不等于允许恢复；运行中事实会继续变化。

## 离线核实与权限

向导分为读取事实、停止旧宿主、检查真实进程/文件/外部效果、原CLI精确事实核实、独占 Web catalog 核实、重启读取。交接可下载脱敏JSON；不提供可一键执行的事实写命令，不预填已检查理由/结果。CLI sessions inspect 只读；verify/verify-request/verify-terminal/verify-environment/verify-subagent/verify-web 仍受原绑定、未决事实、独占锁及原维护限制。核实不宣称原任务成功，不自动重放；操作者需主动决定后续任务。

权限入口仅 default/read-only。default 保留默认策略：读取允许，写入/普通命令逐次审批（精确可信命令例外）；read-only 拒绝非 READ_ONLY 调用，不授予 Shell。保存遵守设置revision、运行/UNKNOWN绑定占用拒绝，下一新任务快照生效。问题回答、计划批准与工具审批互不替代。

## 验收矩阵

| 场景 | 必须证明 |
|---|---|
| SHELL_REQUIRED / 参数失败 | 未启动命令，模式诊断，不自动换Shell |
| 超时/部分清理 | 实际耗时/已知期限，潜在影响，observedClean不作完整清理证明 |
| 未决模型/工具/终端 | 原Recovery集合准确；环境关闭成功不覆盖 |
| 取消竞争/审批过期 | 以落盘结果为准，请求取消不伪造已取消/已批准 |
| 离线交接 | GET/下载无事实写入；旧宿主/锁/未决事实约束仍成立 |
| 权限 | 仅两种值、旧配置兼容、重启/快照，busy/revision及跨入口策略不变 |
| 浏览器 | 实际Java宿主、桌面/窄屏/深色/键盘、错误/敏感内容/不重放 |
