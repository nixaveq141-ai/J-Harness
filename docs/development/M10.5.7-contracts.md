- 扩展表单编辑 MCP、Skills、只读子任务；高级 JSON 保留，使用同一有版本设置保存入口与运行/UNKNOWN 占用门禁。配置不代表连接成功；实际工具以 SDK 注册快照为准。
- 技能根由操作者显式配置，项目根为工作区相对路径，用户根为绝对本机路径。只扫描直属技能目录，有界读取 SKILL.md frontmatter，拒绝链接、穿越、元数据、重名及命令名冲突。不监视、不安装、不热更新。目录文本是不可信输入。
- 扫描技能只提供冻结的 load 工具；资源与脚本继续通过显式 Skills 配置白名单加载，脚本仍经过策略、审批与 durable intent。用户技能根不授予文件或命令权限。
- MCP 根据 initialize 实际能力发现工具及资源/模板。资源列表和模板快照有界；读取限定已发现 URI 或受支持的简单 URI 模板，服务命名空间独立。只支持文本资源，二进制、未知模板表达式明确拒绝；不声称 OAuth、prompt-template 或图像兼容。
- 新工具沿用精确作用域、取消、统一脱敏与工具事件。资源读取错误不伪造成功；有副作用 MCP 工具继续保留 UNKNOWN、不重试。

验收矩阵：浏览器表单增删改/JSON互通、错误配置/忙碌拒绝；SDK 工具实际清单；技能扫描/frontmatter/快照/候选/资源/脚本审批；MCP JSON/SSE工具/资源/模板、分页/重名/Schema/断连/凭据/取消/超大正文；原有 Java、客户端与工作台回归。所有结果按实际证据更新。

## 实现边界

API/SDK 1.13，JSONL/schema 1、Web catalog 4；旧日志无需迁移。新增 `extensions.ready` 是最近一次成功 SDK 装配的工具名、说明及影响级别快照，保持原事实日志权威；旧会话无此事件显示“尚无成功装配记录”，不从当前配置猜测。SDK 在精确作用域注册 DataSanitizer；技能目录插件在注册工具说明前使用它，结果仍经过统一管线脱敏。

`ecosystem.skillRoots` 最多8条 `{id,kind,directory}`，kind为project/user；每根最多64个直属条目、总计16个技能、每文件64KiB、总内容512KiB；扫描共享5秒截止，单次文件读取1秒边界。项目目录拒绝绝对、驱动器相对、根相对、穿越与链接路径；用户根必须为显式本机绝对路径，不接受UNC。仅扫描直属 `目录/SKILL.md`，无递归和文件监视。frontmatter 为受限的单行 name/description（可包单/双引号），不解释完整YAML、块标量、别名或Markdown权限声明；无frontmatter时使用目录名。技能ID为1～24位ASCII字母/数字/下划线/短横线；重名、显式技能冲突及help/quit等命令保留名明确拒绝。资源与脚本不从frontmatter自动授权。

GET `/v1/skills?profile=ID` 只允许已注册profile；读取当前已保存配置的受控目录快照，响应≤480KiB，内容仍不可信。`/技能名`候选只修改页面草稿，发送与加载仍需显式操作/模型工具；装配快照不会随目录更改自动更新。源SHA256指向原文件，脱敏展示不承诺与原字节相同。GET `/v1/tasks/ID/tools` 读取上述持久工具清单（最多256条），不是连接探针或执行入口。

MCP 可声明仅resources能力。每类发现最多8页/128项/512KiB，重复URI/模板或游标循环拒绝；资源读取最多32段、总JSON≤256KiB。注册 `mcp_SERVER__resources`、`mcp_SERVER__resource_templates`、`mcp_SERVER__read_resource`，与远端工具别名碰撞时整次装配失败并回滚。模板只支持一个 `{name}` 变量、单个1～512位ASCII路径段，拒绝百分号编码、斜杠、连续点和其他URI模板表达式；不是完整RFC6570实现。只读取已发现精确URI或上述模板实例，返回URI必须匹配请求且有text，不接受blob。读取错误返回FAILED/取消，不伪造副作用成功；远端工具原UNKNOWN语义保持。匿名HTTP使用无Authorization头；配置tokenEnv却缺值时明确MCP_CREDENTIAL_MISSING，不回退匿名。

保存只变更后续SDK装配配置，保留revision冲突和全局运行/UNKNOWN占用门禁。设置页的表单与高级JSON共享一个草稿；无效JSON保留可修正。确定缺失的MCP凭据在capture/prepareSelection时拒绝受理或开始原消息，原凭据恢复前不回退匿名。其他SDK装配/连接异常继续按原Web工厂不确定规则保留UNKNOWN，不能把未返回SDK实例解释为已确认清理成功；不会产生成功工具清单，也不自动重试或允许修改绕过占用。未增加安装、热更新、OAuth、prompt-template或图片能力。
