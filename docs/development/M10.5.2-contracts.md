## 目录、迁移与占用

磁盘Web目录保留原catalog的独占写者；旧JSONL在独占下先保存强制落盘的原字节备份，再复制到按requestHash寻址的独立任务事实日志，最后追加版本2激活标记。原事实不覆盖、不删除；中途失败不启动模型，重启只补齐一致前缀，损坏/未来版本拒绝，旧宿主遇标记拒绝继续。派生展示不成为执行事实来源。

持久历史与热集分离：最多32个Task执行对象常驻，活跃/UNKNOWN不被驱逐；历史分页每页最多32条，按置顶、创建时间及ID排序。目录扫描逐条释放事实，不把全部任务装入内存。保留底层32MiB/10000事件每日志限制；历史记录存储配额10000条（独立物理资源边界，并非旧32条热集上限），达到配额明确拒绝，不删除历史腾位。requestId的SHA256索引直接读取独立事实，冷历史/归档/重启仍返回原关联，不重复执行。内存型/非磁盘第三方存储保留旧有界兼容路径，不冒充磁盘分页能力。

同一工作区的固定锁由宿主持有，旁侧有界原子占用指针持久记下受理意图及原catalog路径身份。指针先落盘，再受理任务记录，二者完成后才能构造SDK；中断时原catalog从指针恢复为UNKNOWN供核实，不执行。完成事实先落盘再清指针；残留指针只在原目录已有安全结束事实、SDK无未决时修复。不同目录即便catalogId同名也不能接管。切catalog、注册别名、归档均不能解除未决绑定；离线核实必须同时取得原目录、会话及工作区锁并通过SDK恢复检查。锁不能证明不合作执行者停止，保留M10.5.1实际检查要求。

## 操作者入口

可信注册表最多16个工作区，用户显式提交已有绝对目录及名称。宿主检查目录归属、每级链接/重解析点、真实根、元数据路径及禁用目录；重复真实根拒绝。注册不会调用模型，不自动读取目标配置或技能。工作区选择只改变浏览/下次任务绑定，不改变运行中任务。模型文本、网页路径及技能不能注册根。

会话名称/置顶为带独立显示revision的目录事件（执行结算不改变该修订，归档仍核对当前执行/未决事实）；归档/恢复保留全部日志与产物，必须无运行/UNKNOWN及底层未决事实，不能释放仍不明的占用。分叉复制精确事件前缀和已校验产物，父子ID独立，工作区文件不复制；不安全前缀/UNKNOWN拒绝。导出为受限、完整脱敏JSONL快照（不打包产物），大于Web响应限额明确拒绝，不省略成假完整导出。管理动作只走认证同源API，路径/目标文件不由模型指定。

分页游标有界且绑定筛选/宿主修订，名称/置顶/归档或新受理导致旧页过期时重新读取，不自动重提任务。问题回答、审批和后续多轮不在本片实现。

## 验收矩阵

| 场景 | 必须证明 |
|---|---|
| 同目录65个结束任务 | 超过32后继续受理，热集≤32，分页完整，冷requestId幂等 |
| 重启/归档/恢复 | 原事实和关联保留，重启可继续新建，元数据revision冲突拒绝 |
| 旧目录与故障迁移 | 原字节备份、幂等复制、激活前故障无执行，未来/损坏失败关闭 |
| 占用与别名 | 运行/UNKNOWN归档/分叉拒绝，换catalog/别名仍阻塞；原离线核实约束保留 |
| 注册与隔离 | 真实工作区切换，跨根/链接/元数据/秘密目录/错误归属拒绝，不自动执行 |
| 会话操作 | 名称/置顶/分叉前缀与产物/完整导出/归档恢复有实际SDK及浏览器证据 |
| 回归 | 审批/取消/UNKNOWN/密钥/同源/检查点/原诊断保持，最终同JAR/UI |

归档生命周期以SDK日志中的最新archived/restored事实为权威；读取时重新派生目录显示，以覆盖SDK追加后目录元数据未写入的中断及离线CLI变更。注册校验与持锁之间竞争时，已保存注册项保守标为占用，当前宿主不能执行，停止冲突宿主后重启再取得锁；不能因注册返回成功绕过占用。
