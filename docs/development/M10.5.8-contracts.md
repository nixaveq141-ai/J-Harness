# M10.5.8 内容检索与外部 SDK

2026-10-18，已完成本地验收，证据见 [M10.5.8验收](../testing/M10.5.8-validation.md)。保持 M10.5.9/M11 门禁，原审查草稿不纳入本次提交。

检索选择可替换的公共 ContentSearchProvider，默认使用本机有界派生文件索引，不引入 SQLite。查询只覆盖当前 catalog 中已注册工作区的会话；可选择工作区、归档可见性、单会话、token/短语。token 为 Unicode 字母/数字/下划线词，汉字逐字，所有词 AND；短语为忽略大小写的连续原文。排序为匹配分数降序、时间降序、会话/事件 ID 稳定破同分。结果提供 profile/session/event/turn/type、脱敏片段，点击回到事实事件。

派生索引持久内容只来自完整脱敏后的实际事件正文；按事件 ID、源摘要、实际正文复核前缀并增量更新，损坏重建，独占索引锁不影响事实 writer。缓存不是权限或事实来源；不索引浏览器秘密、SDK模型请求副本或配置。查询和索引均有容量/时间上限，大范围明确拒绝并提示缩小范围。分页为有时限的稳定结果快照，后续事件不混入，改变查询/可见范围不能复用游标。

独立 stdio JSON-RPC 2.0 协议版本 `1.0`，先 initialize 协商精确版本，未知字段/方法/版本拒绝。只允许固定会话/任务服务，不提供任意 URL、路径或宿主配置执行接口。CLI `sdk-stdio` 复用现有本机工作台/Java SDK、catalog、幂等、队列、提问、审批、取消及报告服务；内部随机 loopback 会话凭据仅内存，不进 argv、stdout 或日志。

session.open 新建有界草稿句柄，不运行模型、不伪造持久 SDK 会话；首次显式 send_input 受理后返回真实 sessionId，后续消息沿用该会话。也可通过真实 sessionId 重新打开。草稿句柄仅属当前进程；丢响应后显式查询 requestId 受理记录，不自动重发。sessions.list 列举持久实际会话，草稿与持久事实明确区分。EOF/shutdown 关闭本实例拥有的服务，取消进行中的任务并保留 UNKNOWN，不清除历史或重放。

TS/Python 客户端负责相关 ID、有界待决队列、超时、行大小、严格响应解析与自有子进程关闭；超时不自动重试。仅自有进程可在优雅退出期限后终止，不按历史 PID 杀进程。密钥由调用者环境/系统凭据提供，不进入启动参数或诊断文本。不是 Cordis 或上游 SDK 完整兼容承诺。

验收：跨会话/工作区/归档、token/短语/排序/分页、增量/损坏/伪造缓存/容量/锁/脱敏/来源反例；实际浏览器搜索及旧矩阵；TS/Python 各自真实子进程与本机模型替身，覆盖打开/发送/事件/提问/审批/取消/结果、幂等/断线/UNKNOWN/版本/清理。只按产生的证据更新完成状态。

检索边界：256会话/4096命中，单会话4MiB正文/20000文档/8MiB编码索引；查询协作式5秒截止检查，最多4份两分钟快照，页大小1～32（UI20）。每次从当前脱敏事实重新核对缓存正文和关联，仅复用匹配前缀；这是正确性优先的增量缓存，并非无需扫描事实的数据库。JVM占用表加OS锁保护派生文件，祖先链接拒绝，临时文件force后原子替换。快照绑定查询及当前catalog成员/归档可见性，来源回读始终再经原服务授权。

协议与参数见 [stdio契约](M10.5.8-stdio.md)，用户入口见 [使用说明](../examples/m1058-search-sdk.md)。新客户端没有第三方运行依赖；本机测试不替代M10.5.9的三平台、三浏览器和供应链门禁。
