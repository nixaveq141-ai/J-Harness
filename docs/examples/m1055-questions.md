# 模型主动提问

SDK与Web工作台默认提供 ask_user。模型需要补充信息时，会出现单选、多选或文字回答卡。推荐项只是预选；点击“提交回答”才提交，也可以明确“跳过问题”。问题最多等待300秒，界面会显示截止时间。

回答期间，原续聊草稿保持保留。问题编辑会在短暂延迟后保存到当前宿主的脱敏内存；只有显示保存确认后，刷新才可恢复。宿主重启会丢弃未提交草稿和未完成等待。答案、草稿不会写入浏览器存储；浏览器只保留用于核对的请求标记。

如果提交后网络中断，界面显示待核对并通过GET读取状态，不自动重复提交。“清除本页标记”不会撤销后台可能已经收到的回答。已回答、已跳过、超时、取消和中断分别显示，不能在已关闭的问题上补交。

回答仅提供信息。模型随后要求写文件、执行命令或推进计划时，仍须按原策略进行审批。回答不会授予权限，也不会修改当前模型和预算。

每个会话最多64个问题，每页8条；问题最长2048字符，选项最多8个，文字回答最长4096字符。公共服务、接口和事件关联见[主动提问契约](../development/M10.5.5-contracts.md)，验收见[验证记录](../testing/M10.5.5-validation.md)。
