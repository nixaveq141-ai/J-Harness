# M10.5.6 对话与内容查看

启动 `web-ui.cmd`，打开已有会话或新建任务。主区域默认显示用户/助手对话、工具结果和变更卡；“展开执行细节”保留事件原文入口。代码块可复制，Markdown 不执行 HTML，外部图片不自动加载。

模型响应时，“临时流式输出”显示经过跨块脱敏的安全片段。“停止显示”只暂停本页读取，“继续显示”读取现有快照；取消任务仍使用原取消按钮。完整且已持久的助手消息替代临时片段。刷新不会重新请求模型，宿主重启后无法恢复临时字节；断流和取消不冒充完整回答。

右侧“文件”只读取会话绑定的已注册本地工作区。可以逐层浏览、输入相对路径，或点击对话中的文件/行号引用。预览是当前文件，文件发生变化后需明确重新读取，不把旧页和新页拼接。该预览不授予模型写权限。非本地环境当前不提供文件树回退。

“产物”列出此会话事实中明确引用的产物。展开后分页查看，下载生成经过脱敏的文本文件；原始产物 SHA 与脱敏内容 SHA 分别显示。大事件的“正文已省略”入口可以分页回读，产物过期、损坏或不属于本会话时明确报错。

Diff 面板展示当时记录的 git_diff；“当前文件内容”另行读取当前版本。查看不会执行 Git 或自动应用补丁。

请求耗时和 token 来自实际记录，未提供的数值显示未知；预算上界不是实际账单。移动端可以收起输入区浏览内容，再展开继续原草稿。

文件预览限 UTF-8 文本 1 MiB，目录每层最多 200 项；产物最多 4 MiB，正文每页最多 16384 字符，临时流式缓冲最多 65536 字符。元数据、越界路径、链接与二进制不提供预览。
