# Web 工作台设置

双击英文入口`web-ui.cmd`，页面自动连接后，在左侧点击「设置」。升级后需要关闭旧启动窗口（输入`:quit`）并重新打开入口，正在运行的旧服务不会自动变成新版。

## 模型与连接

1. 点击「添加连接」，填写连接名称、OpenAI兼容API基础URL、服务端模型名称和API Key。
2. 点击「设为默认连接」，再点击「保存设置」。后续任务的default配置使用这个连接。可创建最多16个连接。
3. 修改连接时，API Key留空保留原密钥；填写新值则替换系统凭据。删除连接并保存会清理该连接的托管凭据。

API Key保存到当前Windows登录用户的Credential Manager，服务重启后读取；不写明文配置、URL、日志或Web Storage，不回显原文。模型API Key与后台自动建立的本机会话独立；用户无需手动填写Web token。M10.5.4实施中的版本新增macOS Keychain及Linux Secret Service/libsecret适配，不回退明文文件；macOS尚待真实runner验证。Linux需要当前用户D-Bus会话、libsecret和已解锁的默认凭据集合；缺失/锁定显示不可用。启动或解锁服务后重启工作台，可为新连接改用环境变量。已有凭据引用读取失败时拒绝受理，不静默使用备用密钥。凭据在当前宿主内存缓存，外部直接更改凭据后需重启服务。

「环境变量与费用限制」可填写备用密钥变量名、服务专用thinking参数，以及每个连接独立的费用上限、币种、每百万token价格和输入预留。新连接默认不发送DeepSeek专用thinking参数，也没有费用上限；如需要费用保护应启用并填写已核实价格。修改URL或模型名会清空旧价格，重新填写后才能保存已启用费用保护的连接。任务步数/时限/上下文等仍沿用启动配置。

保存不测试远端连接、不发送模型请求。创建任务才会实际使用模型。未配置密钥会在任务受理前明确拒绝，不产生UNKNOWN任务。没有自动读取服务商模型列表或检测真实单价。

## 插件与扩展

- 「任务规划」和「上下文压缩」可直接开关。
- 展开MCP服务、Skills、只读子任务、网页来源，按页面示例编辑受校验的JSON配置后保存。MCP可配置stdio/HTTP；MCP认证当前仍通过tokenEnv引用宿主环境变量，不在配置中填明文token。
- Skills目录和文件需要已经位于工作区，配置是注册入口，不会下载或创建技能文件；资源/脚本遵守现有白名单、路径和审批规则。页面有示例可对照。
- 新任务启动时装配扩展。通过任务目标要求模型使用相应工具，执行记录出现在事件时间线中。例如注册guide技能后，可要求「阅读guide技能并分析这个项目」；最终是否调用以真实事件为准。
- 核心组件只读展示，不提供任意JAR安装、插件市场或运行中热加载。

设置只在保存后生效。有运行中或UNKNOWN占用任务时拒绝修改；UNKNOWN仍须先停旧宿主、按原CLI流程离线核实。多页面保存使用revision，旧版本被拒绝后重新读取，避免覆盖。未保存修改会阻止侧栏离开，并在刷新/关闭时提示；「放弃修改并重新读取」明确丢弃草稿。网络响应不明时重新读取核对，不会自动重发保存。

非秘密设置位于工作区`.jharness/settings/workbench.json`，不覆盖原CLI配置或命名Profile/Bundle/Preset目录。此文件不含密钥，只含系统凭据引用。设置与凭据库不是跨系统事务：异常中断可能留下不可见的托管旧项；若页面报告旧凭据清理失败，可在Windows凭据管理器中检查本项目`J-Harness/`项。不要删除其他工作区仍使用的凭据。

## 权限与失败诊断（M10.5.1）

设置的「权限」页显示default/read-only当前值和作用范围，只影响后续新任务。只读模式由后端策略拒绝写入/命令；默认模式仍逐次审批有影响的操作。回答问题、计划批准和工具审批各自独立。失败任务的诊断、未决事实及只读离线交接见[m10.5.1-recovery.md](m10.5.1-recovery.md)。不提供在线清除UNKNOWN或自动重放。
