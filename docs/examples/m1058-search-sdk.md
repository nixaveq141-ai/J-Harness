# 内容检索与外部 SDK

工作台左侧“内容检索”查询消息、工具结果和问题回答的脱敏实际正文。原侧栏搜索仍是任务 ID/状态筛选。选择所有已注册工作区或某个工作区，归档范围可选未归档、已归档、全部；打开会话后可选“仅当前会话”。

“所有词匹配”忽略大小写，Unicode 字母/数字/下划线连续组成词，汉字逐字，所有词必须出现；`alpha` 不匹配 `alphabet`。“连续短语”要求忽略大小写后的连续原文，包括空格及标点。重复词出现次数增加匹配分，同分按时间降序及来源 ID 稳定排序。每页20条；加载更多使用两分钟结果快照，新消息须重新查询。归档或查询范围改变会使旧游标失效。

每条结果列出工作区、会话、事件/轮次与脱敏片段。“读取来源事件”分页查看确切事实正文；“打开来源会话”只读取已有会话。“索引维护”可显式重建当前范围再查询；缓存损坏自动从事实重建，不执行任务、不更改日志。停止读取仅停止浏览器等待，不表示撤销服务端已有查询。

默认一次最多256个会话、4096条匹配；正文索引每会话4MiB/20000条，编码文件8MiB。超限须缩小范围或使用原会话事件分页。空查询、错误范围、游标过期、索引占用和未配置提供方均明确拒绝；不会自动改用未授权工作区。

外部集成见 [SDK 与可运行示例](../../sdk/README.md)及 [stdio 协议](../development/M10.5.8-stdio.md)。TypeScript 客户端需要支持原生 TS stripping 的 Node（验收为24），Python 模块只用标准库。SDK 通过独立版本1.0的 JSON-RPC 启动自有 Java 子进程，复用既有受理、队列、审批、提问、取消、事实和报告服务；Java API/SDK 为1.14，JSONL1/Web目录4保持。

打开草稿不运行模型；显式发送后才产生真实会话。保存每条输入 requestId：超时或断线先核对受理记录，禁止自动重发。回答问题不等于批准工具，UNKNOWN禁止自动续跑。关闭只清理自己的进程；历史保留，可能仍需离线核实。不要把模型密钥放在启动参数、任务文本或明文配置中。
