# 工作区与会话管理

双击根目录 `web-ui.cmd`。左侧“工作区”筛选历史，也决定下一次新建任务的执行根；“全部工作区”只合并浏览，不创建新的执行根。点击“注册工作区”，填写你拥有的已有绝对目录及名称；注册不会调用模型，也不会加载目标目录的配置。模型及权限仍在宿主设置中管理。

选择会话后展开“会话管理”：保存名称、置顶、导出、分叉、归档或恢复。名称未保存时先保存或重读，再切换会话。归档保留日志和产物，使用左侧归档筛选找到并恢复。运行中或结果待核实的工作区不能归档、分叉或导出，也不能通过别名或换目录解除占用。

导出下载完整脱敏 JSONL，页面校验 SHA256；不包含产物文件。超过页面限额时明确拒绝，请停止宿主后使用 CLI sessions export。分叉默认截至最后已加载事件，也可填写安全事件 ID；会复制该前缀及已校验产物，创建独立会话，不复制工作区文件、不调用模型。本片尚未提供分叉后继续对话；多轮属于 M10.5.3。

历史按置顶及创建时间分页，每页最多32条；旧页因新任务或管理变更过期时回到第一页。32是常驻 Task 对象热集上限，不再限制累计会话数。磁盘历史配额10000条，每份事实日志仍受既有限额约束；不自动删除历史腾位。

旧目录在独占锁下先备份原字节，再迁移到分任务事实日志，最后激活版本2。备份及旧目录均保留；旧宿主不能继续写新目录。迁移中断、UNKNOWN 和未确认受理不自动重放；按执行诊断的离线核实流程处理。工作区注册表位于初始工作区 `.jharness/settings/workspaces.json`，最多16个根；目标链接、重解析点、秘密/元数据目录及错误归属被拒绝。
