## 独立复核发现与修复

原中继只在原始响应字节中匹配完整凭据，JSON Unicode 转义可绕过这个检查。现在会在转发成功 SSE 和保存其收据之前，递归检查解码后的 JSON 字符串键和值。离线反例覆盖厂商密钥和本地 token，各自在嵌套值及键中的 Unicode 转义；关闭新检查时，四个响应断言及无收据断言全部失败；补强后全部通过，失败仍保留原预留。

该补强发生在上述真实请求之后。真实运行使用的驱动 SHA 为 `bc3868d3eff96999c8b03da979765746ee09db43a9c570fe4fcd5be6b1615786`，其精确字节已归档；补强后的驱动 SHA 单独记录在机器结果中。没有为了复测而再发送付费请求。凭据检查覆盖完整原始 token 和解码后的单个 JSON 字段，不宣称防住任意编码或跨字段拼接的恶意外传。

离线验证：原 SSE 8 项再次通过；加入新反例后的 SSE **9 项通过**，包括实际打包 CLI 对本地模拟 SSE 的工具往返；原费用账本 **9 项通过**。独立审计核对 62 条原事实和所有来源、收据，新增厂商调用为零。日志与审计脚本 SHA 见机器记录。
