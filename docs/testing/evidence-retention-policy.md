# 验收证据保存与恢复

生效：2026-10-27。本政策处理GAP-15的治理建议，不改变任何历史验收结果。

GitHub完整CI和新Docker专项的原始制品请求保留90天。每次接受结果必须同时记录仓库、commit、runId、平台、制品ID、原ZIP的GitHub摘要/本地摘要、创建和到期时间。失败与中断结果也保留；不能用重新生成的报告覆盖旧失败，不能把不同提交/轮次拼成同一次通过。

在每次阶段验收收尾时、CI到期前以及执行本地clean/迁移工作区前，应导出原始包。指定保存负责人为仓库维护者；自动化负责校验和生成导出，不擅自选择外部存储、公开运行数据或上传密钥。原会话和构建缓存不提交Git。清理只可在独立副本校验通过且维护者明确同意后进行，本脚本不删除原证据。

[导出脚本](../../scripts/export-acceptance-evidence.py)读取已独立审计的三平台结果与原始获取清单，要求三原包同runId/commit、身份不重复且摘要与GitHub一致。它把原ZIP逐字节放进新ZIP并回读核对；原始结果JSON和manifest一并保存，现有输出拒绝覆盖，不提取或执行ZIP内容。

```powershell
python scripts/export-acceptance-evidence.py --result docs/testing/M10-gap-remote-ci-2026-10-27.json --originals .build-cache/gap-remote-20261027/originals --output .build-cache/evidence-vault/accepted-40467690361-dae011a-originals.zip
```

本次已生成84,650,454字节的本地导出，SHA-256为`0c6faf3b5832da040589977c708f974e24fb73f9d25299fc2b263bd997ea67fd`。它绑定历史已验收`dae011a`/`40467690361`，不覆盖后续715项修复。三原包当前到期为2027-01-25，不能等同永久保留。

维护者应将导出包复制到工作区之外的独立存储，再在目标端核对整个包SHA。恢复时先核整个包SHA，再核manifest中每个原ZIP的SHA与原始获取清单，最后使用对应提交的审计器重新检查原包；任何一步失败都不得恢复“已通过”状态。不要用修改后的当前契约去认证较旧提交。
